- **Rules Applied (Phase 14):**
  - Covers 100% of requirements in scope (not a sample).
  - Non-1:1 relationships are explicitly represented across rows where a requirement maps to multiple components or stores.
  - `N/A` is accompanied by an explicit justification (e.g., project-governance deliverables with no runtime software/database component).
  - `[PLANNED]` denotes database tables/labels/collections documented in `Database Design Ver 1.1` as target extensions not yet created in the MVP codebase.
